# SQL 基础

## 1. SQL 概述

SQL 的完整名称是 **Structured Query Language**，意思是“结构化查询语言”。

SQL 用于操作关系型数据库，包括定义数据库结构、对数据进行增删改查，以及管理用户和访问权限。

SQL 有统一标准，不同数据库产品也有各自的语法扩展。以下笔记以 MySQL 为例。

## 2. SQL 通用语法

### 2.1 书写方式

SQL 语句可以写在一行，也可以分成多行书写。在 MySQL 命令行客户端中，通常以英文分号 `;` 结束一条语句。

同一条语句也可以分行书写，可以使用空格、换行和缩进增强可读性，但不能把一个关键字拆开。

### 2.2 大小写

SQL 关键字不区分大小写，建议统一使用大写。

```sql
SELECT 1 + 1;
select 1 + 1;
```

以上两条语句含义相同。

数据库名和表名是否区分大小写，与操作系统和 MySQL 配置有关，不能把“关键字不区分大小写”理解成所有内容都不区分大小写。

书写时可以统一约定：

- 关键字使用大写，如 `SELECT`、`CREATE`、`INSERT`。
- 数据库名、表名和字段名使用小写，多个单词用下划线连接，如 `student_info`。
- 字符串使用英文单引号，如 `'张三'`。

### 2.3 注释

单行注释：

```sql
-- 这是一行注释
SELECT 1 + 1;

SELECT 1 + 1; -- 计算 1 + 1
```

MySQL 中使用 `--` 注释时，后面需要跟空白字符，通常写一个空格。

多行注释：

```sql
/*
这是多行注释。
可以在这里说明 SQL 语句的作用。
*/
SELECT 3 + 3;
```

## 3. SQL 分类

按本课程的学习方式，SQL 主要分为 DDL、DML、DQL、DCL 四类。

| 分类  | 英文全称                       | 中文名称   | 作用               | 常见语句                                        |
|-----|----------------------------|--------|------------------|---------------------------------------------|
| DDL | Data Definition Language   | 数据定义语言 | 定义数据库、表、字段等数据库对象 | `CREATE`、`ALTER`、`DROP`、`TRUNCATE`          |
| DML | Data Manipulation Language | 数据操作语言 | 对表中的数据进行增、删、改    | `INSERT`、`UPDATE`、`DELETE`                  |
| DQL | Data Query Language        | 数据查询语言 | 查询表中的记录          | `SELECT`                                    |
| DCL | Data Control Language      | 数据控制语言 | 管理数据库用户和访问权限     | `CREATE USER`、`ALTER USER`、`GRANT`、`REVOKE` |

可以这样区分：

- **DDL**：创建一张学生表，或给表增加一个字段。
- **DML**：添加一名学生，或修改、删除某条学生记录。
- **DQL**：查询哪些学生的成绩超过 80 分。
- **DCL**：创建一个账户，并允许它查询学生表。
